# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report security issues by emailing the developer contact listed in the
app's About screen.

Include:
- A description of the vulnerability and its impact
- Steps to reproduce or a proof-of-concept
- Relevant file paths or line numbers

You will receive a response within 72 hours. Please allow reasonable
time for a fix before any public disclosure.

## Scope

- On-device inference and data handling
- Local SQLite storage
- Model download and file handling
- Credential or secret leakage in the binary or source

## Private Vulnerability Reporting

GitHub's private vulnerability reporting is only available on public
repositories. Once this repo is public, it can be enabled via
**Settings → Security and analysis → Private vulnerability reporting**.
Until then, please use the email route above.
