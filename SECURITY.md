# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report security issues privately by emailing the developer contact listed in the app's About screen, or by using [GitHub's private vulnerability reporting](https://github.com/Sandipan006/lokalmind-app/security/advisories/new).

Include:
- A description of the vulnerability and its impact
- Steps to reproduce or a proof-of-concept
- Any relevant file paths or line numbers

You will receive a response within 72 hours. We ask that you allow reasonable time for a fix before any public disclosure.

## Scope

- On-device inference and data handling
- Local SQLite storage
- Model download and file handling
- Any credential or secret leakage in the binary or source
